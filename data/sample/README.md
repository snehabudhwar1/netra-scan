# Sample data

Ten example retina photos from APTOS 2019 (2 per grade, 0 to 4), already cropped to 512x512, with their grades in `labels.csv`.

The full datasets are too large for GitHub. Download them here:

- APTOS 2019: https://www.kaggle.com/c/aptos2019-blindness-detection
- IDRiD: https://idrid.grand-challenge.org

Put the full data in `data/aptos/` and `data/idrid/` as described in the main README.
